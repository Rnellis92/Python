🐍 Python Programming Project
Project Overview

This project was completed as part of a Data Technician Bootcamp and demonstrates the development of fundamental Python programming skills. The project focused on building logical programs, performing calculations, and creating interactive programs that respond to user input.

Skills Demonstrated
Variables – storing and working with different types of data.
print() function – displaying information and results to users.
input() function – allowing users to enter information and interact with programs.
Type casting – converting data between types, such as strings and integers, to perform calculations.
if statements – creating conditions and decision-making logic.
for loops – repeating tasks and processing a sequence of values.
while loops – repeatedly running code while a condition is met.
Calculations – using Python operators to perform mathematical operations and process data.
User interaction – developing programs that respond to and validate user input.
Project Learning

Through these exercises, I developed a stronger understanding of programming logic and problem-solving. I learned how different Python concepts can be combined to create programs that make decisions, repeat tasks, perform calculations, and interact with users.

This project provided a foundation in Python that can be applied to data analysis, automation, and more advanced programming tasks.
